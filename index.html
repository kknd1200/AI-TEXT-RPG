이 홈페이지는

순수 HTML · CSS · JavaScript로만 만들어졌습니다. 프레임워크도, 빌드 도구도, 서버도 필요 없습니다. 파일을 그대로 GitHub Pages나 아무 정적 호스팅에 올리면 그 순간 서비스가 됩니다.

  • 바로 실행게임은 플레이어 화면의 iframe 안에서 돌아갑니다. 전체화면 버튼도 있습니다.
  • 검색과 필터게임이 늘어나도 이름·태그로 즉시 찾을 수 있습니다.
  • 외부 게임도 OK다른 곳에 배포한 게임은 URL만 등록하면 목록에 함께 노출됩니다.
  • 테마 기억밝은/어두운 테마 선택이 브라우저에 저장됩니다.

내 게임 추가하기

  1. 1. 게임 파일을 넣습니다

    games/ 아래에 폴더를 만들고 index.html을 넣습니다.

    games/
  my-game/
    index.html
    style.css
    game.js

  2. 2. 목록에 등록합니다

    games/games.js의 배열에 항목을 하나 추가합니다.

    {
  id: 'my-game',
  title: '내 게임',
  tagline: '한 줄 소개',
  path: 'games/my-game/index.html',
  tags: ['퍼즐'],
  emoji: '🧩',
  accent: ['#f97316', '#ef4444'],
  status: 'playable'
}

  3. 3. 끝입니다

    새로고침하면 카드가 나타나고 play.html?game=my-game에서 실행됩니다.
