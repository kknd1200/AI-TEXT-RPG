# Turn-RPG — 텍스트 전략 방치 던전

브라우저에서 바로 즐기는 텍스트 기반 전략/방치형(idle) 턴제 던전 게임 뼈대입니다. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 게임 소개

- **장르**: 전략 + 방치형(idle) 하이브리드
- **화면**: 그래픽 없이 텍스트와 ASCII 게이지만으로 구성
- **플레이 방식**: 자동전투(방치)와 수동전투(턴제 커맨드) 두 가지를 자유롭게 전환하며 플레이

### 자동전투 (방치형)
파티가 일정 주기로 자동으로 적과 전투합니다. 게임을 닫았다가 다시 열면 자리를 비운 시간만큼(최대 8시간) 전투 결과를 계산해 골드/처치/스테이지 진행을 한 번에 정산해 줍니다.

### 수동전투 (턴제 전략)
[모드 전환] 버튼으로 전환하면 자동 진행이 멈추고, 매 턴마다 공격/스킬/방어/휴식 중 하나를 직접 선택해 파티 전체에 명령을 내릴 수 있습니다.

### 전략 요소
- **전열/후열 편성**: 각 영웅을 전열(피해를 더 많이 받음) 또는 후열로 배치해 원거리 딜러를 보호
- **출전/대기**: 최대 4명까지 전투에 참여시키고 나머지는 대기시켜 교체 가능
- **모집/훈련**: 골드로 새 영웅(전사/궁수/마법사/힐러)을 모집하거나 기존 영웅을 훈련시켜 즉시 레벨업
- **보스**: 10스테이지마다 강력한 보스 출현

## 파일 구조

- `index.html` — 페이지 구조와 최소한의 스타일
- `js/state.js` — 클래스/적 정의, 세이브 저장·불러오기, 비용 계산
- `js/combat.js` — 전투 라운드 해석(자동/공격/스킬/방어/휴식), 오프라인 시뮬레이션
- `js/main.js` — 텍스트 렌더링과 이벤트 연결, 게임 루프

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.
