# 엘리멘탈 테이머 (AI-TEXT-RPG)

몬스터를 잡고 · 기르고 · 합쳐서 강해지는 **턴제 텍스트 RPG**. 파이썬 표준 라이브러리만 쓴다.

- 오리지널 도감 **132종** (6속성 × 22종, 6등급)
- 패시브 스킬 20종 × 3레벨, 아이템 26종, 사냥터 18곳 + 미지의 섬
- 조합 · 강화 · 패시브 장착 · 배틀존 · 몬스터마트 · 우체통 · 저장/불러오기

## 실행

Python 3.10 이상. 설치할 것 없음.

```bash
python3 main.py            # 플레이
python3 main.py --demo     # 자동 전투 데모 (고정 시드)
python3 -m unittest discover -s tests
python3 tools/balance_check.py    # 전투 밸런스 시뮬레이션
python3 tools/generate_roster.py  # 도감 다시 생성
```

## 게임 시스템

**전투** — SPD가 높은 쪽부터 움직인다. 커맨드는 물리공격 / 스킬공격 / 방어 / 아이템 /
포획 / 도망, 그리고 자동 전투. 스킬 공격은 속성 상성 배율을 그대로 받고 물리 공격은
그 40%만 받는다. 자동 전투는 두 커맨드의 기대 피해를 비교해 더 센 쪽을 고른다.

**속성** — 수 · 화 · 목 · 풍 · 광 · 악. `화 > 목 > 풍 > 수 > 화` 순환이고 광과 악은 서로에게
강하다. 속성마다 잘하는 스탯이 다르다(화=물리공격, 광=스킬공격, 풍=속도, 목=체력,
악=복합, 수=밸런스). 속성별 능력치 총합은 같게 맞춰 두었다.

**육성** — 전투마다 FOOD(허기도)가 줄고 0이 되면 능력치가 떨어진다. FEEL(교감도)이
999에 닿으면 진화해서 능력치가 오르고 패시브 슬롯이 3칸에서 6칸으로 늘어난다.
마블을 먹이면 허기도와 교감도가 함께 오른다.

**파티 포인트** — 등급이 높은 몬스터일수록 자리를 많이 먹는다(common 1 … god 9).
쓸 수 있는 총량은 테이머 등급과 미지의 섬 레벨로 늘어난다.

**공방**
- *조합* — 같은 등급 두 마리를 합쳐 한 등급 위를 노린다. 실패하면 한 등급 아래가
  나오고, common은 실패해도 common이다. 패시브는 50% 확률로 계승된다.
- *강화* — BRAIN(지능)을 올린다. 지능이 높을수록 성공률이 떨어진다.
- *패시브 장착* — 재료와 골드를 들여 붙인다. 한 번 붙이면 뗄 수 없고, 같은 스킬을
  두 번 붙일 수는 없지만 재료를 더 들여 레벨을 올릴 수는 있다.

**배틀존 · 마트 · 우체통 · 미지의 섬** — 퀵/랭킹/친선 배틀과 3연전 챌린지, 랭킹판,
배틀로그, 몬스터 매매, 하루 한 번 선물, 섬 레벨에 따라 상위 등급이 열리는 사냥터와
보물상자, 친구 섬 방문까지. **전부 서버 없이 이 저장소 안에서 흉내 낸 오프라인
구현이다.** 실제 통신은 하지 않고, 상대와 매물은 날짜·이름·랭킹 포인트를 시드로
결정적으로 생성한다. 나중에 진짜 서버를 붙이더라도 `tamer/network.py` 의
"상대 가져오기 / 결과 정산하기" 경계만 바꾸면 된다.

## 구조

```
data/roster.json         오리지널 몬스터 도감 (generate_roster.py 결과물)
data/passives.json       패시브 스킬 정의
data/items.json          아이템과 드롭 표
data/world.json          사냥터
data/rules/balance.json  전투 계수 — 밸런스 조정은 전부 여기서
tamer/data.py            데이터 로더
tamer/models.py          테이머 / 몬스터 개체
tamer/rules.py           데미지 · 상성 · 포획 · 경험치 계산식
tamer/passives.py        패시브 효과 해석기
tamer/battle.py          턴제 전투 엔진
tamer/workshop.py        조합 · 강화 · 패시브 장착
tamer/network.py         배틀존 · 마트 · 우체통 · 미지의 섬 (오프라인)
tamer/save.py            저장 / 불러오기
tamer/world.py           사냥터와 출현
tamer/cli.py             텍스트 UI
tools/generate_roster.py 도감 생성기
tools/balance_check.py   밸런스 시뮬레이터
tools/extract_apk.py     (선택) 안드로이드 APK 에셋 추출기
docs/design.md           설계 기록 — 수치를 왜 그렇게 정했는지
docs/data-format.md      APK 에셋 포맷 역분석 기록
```

## 밸런스

`tools/balance_check.py` 로 확인한다. 목표는 **같은 종끼리 붙었을 때 평균 8~13턴,
선공 승률 50%**, 그리고 **상성이 유리한 쪽이 확실히 이기는 것**이다. 계수는 전부
`data/rules/balance.json` 에 있어서 코드를 건드리지 않고 조정할 수 있다.

## 저작권

이 저장소에 들어 있는 몬스터 이름 · 스킬 · 설명 · 능력치 · 지명 · 아이템은 전부
**이 프로젝트에서 새로 만든 것**이고, 특정 상용 게임의 데이터를 옮겨 담지 않았다.
도감은 `tools/generate_roster.py` 가 만들어 낸다.

`tools/extract_apk.py` 는 안드로이드 APK 에셋 컨테이너를 읽는 도구다. 이 도구가
읽어 낸 데이터는 저장소에 포함하지 않고 `.gitignore` 로 막아 두었다. 각자 정당하게
가진 APK에서 뽑아 `TAMER_ROSTER=extracted` 로 돌려볼 수는 있지만, 그렇게 뽑은
데이터는 원저작자의 저작물이니 배포하거나 공개하지 않는다.
