# AI-TEXT-RPG — 웹게임 아케이드

브라우저에서 바로 돌아가는 **웹게임 홈페이지**와, 그 홈페이지에서 실행되는
텍스트 RPG **「잊혀진 탑」**입니다.

순수 HTML · CSS · JavaScript로만 만들어졌습니다. 프레임워크도, 빌드 도구도,
`npm install`도 없습니다. 파일을 정적 호스팅에 올리면 그대로 서비스가 됩니다.

---

## 바로 실행해 보기

가장 간단한 방법 — 저장소 폴더에서 아무 정적 서버나 띄웁니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

> `index.html`을 파일로 직접 열어도(`file://`) 동작합니다.
> 게임 목록을 `fetch` 대신 일반 `<script>`로 불러오기 때문에 CORS 문제가 없습니다.

---

## 홈페이지에 내 게임 추가하기

### 1. 게임 파일을 넣습니다

`games/` 아래에 폴더를 만들고 `index.html`을 둡니다.

```
games/
  my-game/
    index.html
    style.css
    game.js
```

### 2. `games/games.js`에 한 줄 등록합니다

```js
window.GAME_REGISTRY = [
  // ...기존 게임들
  {
    id: 'my-game',                      // URL에 쓰이는 고유 아이디
    title: '내 게임',
    tagline: '카드에 보일 한 줄 소개',
    path: 'games/my-game/index.html',   // 실행할 경로
    tags: ['퍼즐', '싱글플레이'],        // 검색·필터에 사용
    emoji: '🧩',                        // 카드 커버 이모지
    accent: ['#f97316', '#ef4444'],     // 카드 커버 그라디언트
    status: 'playable',                 // playable | wip | soon
    players: '1인',
    updated: '2026-09-02'
  }
];
```

### 3. 끝입니다

새로고침하면 카드가 나타나고 `play.html?game=my-game`에서 실행됩니다.
플레이어 화면은 다시 시작 · 새 탭으로 열기 · 전체화면 버튼을 함께 제공합니다.

### 다른 곳에 배포한 게임 연결하기

이미 어딘가에 호스팅 중인 게임은 전체 URL과 `external: true`만 지정하면
목록에 함께 노출되고 새 탭으로 열립니다.

```js
{ id: 'remote', title: '외부 게임', path: 'https://example.com/game/',
  external: true, tags: ['외부'], emoji: '🌐', status: 'playable' }
```

## GitHub Pages로 배포하기

이 저장소에는 Pages 배포용 워크플로가 들어 있습니다
(`.github/workflows/deploy-pages.yml`).

1. GitHub 저장소 → **Settings → Pages** 로 이동합니다.
2. **Source**를 **GitHub Actions**로 바꿉니다.
3. 기본 브랜치에 푸시하면 자동으로 배포됩니다.

주소는 `https://<사용자명>.github.io/<저장소명>/` 형태가 됩니다.
모든 경로를 상대 경로로 작성했기 때문에 하위 경로에 배포해도 그대로 동작합니다.

> 워크플로 없이 **Deploy from a branch**로 배포해도 됩니다.
> Jekyll이 파일을 건드리지 않도록 `.nojekyll` 파일을 이미 넣어 두었습니다.

## 게임: 잊혀진 탑

층을 오르며 얼마나 높이 도달하는지를 겨루는 텍스트 로그라이트입니다.

- **직업 3종** — 전사(버티며 싸움) · 도적(속도와 치명타) · 마법사(방어 관통 화력).
  각자 고유 기술과 성장 곡선이 다릅니다.
- **한 층 = 통로 3~4개.** 전투 · 이벤트 · 보물 · 야영 · 상인이 무작위로 나옵니다.
- **5층마다 층주.** 도망칠 수 없고, 잡으면 전리품과 회복을 줍니다.
  층주 목록을 한 바퀴 돌면 더 강해진 모습으로 다시 나타납니다.
- **전투** — 공격(MP 소량 회복) / 고유 기술 / 방어(받는 피해 절반) / 아이템 / 도주.
  기본 공격으로 MP를 모아 기술을 쓰는 순환 구조입니다.
- **저장** — 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.
  쓰러지면 저장은 지워지고 기록만 **전당**에 남습니다.

### 밸런스에 대해

전투·성장 공식을 그대로 옮긴 시뮬레이터로 직업별 3,000회씩 돌려 조정했습니다.

| 직업 | 도달 층 중앙값 | 상위 10% | 5층 전 사망 | 20층 돌파 | 층주에게 패배 |
|------|----------------|----------|-------------|-----------|----------------|
| 전사 | 9층 | 15층 | 0% | 3% | 21% |
| 도적 | 9층 | 15층 | 0% | 3% | 22% |
| 마법사 | 7층 | 13층 | 2% | 1% | 26% |

첫 층주(5층)가 실질적인 관문이고, 대부분의 도전은 6~15층에서 끝납니다.
20층을 넘기면 상위 3% 안에 드는 기록입니다.

방어력은 뺄셈이 아니라 비율로 피해를 줄입니다(`100 / (100 + 방어 × 3)`).
덕분에 방어가 높아도 무적이 되지 않고, 낮아도 즉사하지 않습니다.

## 폴더 구조

```
.
├── index.html              홈페이지 (게임 목록 · 검색 · 태그 필터)
├── play.html               게임 플레이어 셸 (iframe · 전체화면)
├── assets/
│   ├── css/style.css       공통 스타일 (밝은/어두운 테마)
│   ├── css/play.css        플레이어 화면 스타일
│   ├── js/main.js          카드 렌더링 · 검색 · 테마
│   └── js/play.js          게임 로딩 · 다시 시작 · 전체화면
├── games/
│   ├── games.js            게임 레지스트리 ← 여기에 게임을 등록합니다
│   └── text-rpg/           「잊혀진 탑」
│       ├── index.html
│       ├── style.css
│       ├── data.js         직업 · 몬스터 · 아이템 · 이벤트
│       └── game.js         전투 · 성장 · 저장 로직
└── .nojekyll
```

## 브라우저 지원

최신 Chrome · Edge · Firefox · Safari에서 동작합니다.
밝은/어두운 테마는 시스템 설정을 따르고, 선택하면 브라우저에 기억됩니다.
