# 미지의 섬 프라이빗 서버

배틀몬스터3 / Monster3K (`com.ensony.battlemonster3`) 의 온라인 콘텐츠
**미지의 섬**을 다시 살리기 위한 서버입니다.
원 서버(`218.50.3.88:5018`)가 내려간 뒤로 못 하게 된 멀티플레이를,
직접 띄운 서버로 대체합니다.

결론부터: **됩니다.** 클라이언트가 쓰는 프로토콜은 평문 TCP 이고 암호화나
서명 검증이 없어서, 규격만 맞춰 응답하면 그대로 동작합니다.

## 뭐가 들어 있나

```
docs/protocol.md    복원한 프로토콜 명세 (명령 33개 전부)
docs/setup.md       서버 실행 · 클라이언트 패치 · 서명 · 식별자 문제
docs/reversing.md   어떻게 알아냈는지 기록

server/             서버 본체 (파이썬 표준 라이브러리만 사용)
tools/              분석 도구 + APK 패처 + 가짜 클라이언트
tests/              코덱 · 핸들러 테스트
```

## 3분 만에 돌려보기

```bash
# 1. 서버
python3 server/main.py -v

# 2. 다른 터미널에서, 게임과 똑같은 패킷을 보내는 가짜 클라이언트로 확인
python3 tools/fake_client.py --phone 01011112222 walkthrough
python3 tools/fake_client.py --phone 01033334444 walkthrough
```

두 번째 플레이어의 `island_count` 가 1 이상이고 `island_target` 이
상대 식별자를 돌려주면, 서로가 섬에서 보이는 상태입니다.

```bash
# 3. 실제 단말에 넣을 APK 만들기 (서버 IP를 박아 넣음)
python3 tools/patch_client.py 원본.apk 203.0.113.10 -o monster3k-private.apk
# 그 뒤 서명 필요 — docs/setup.md 참고
```

## 지금 되는 것

| 기능 | 명령 | 상태 |
|---|---|---|
| 유저 등록 / 서버 시각 | `0x23`, `0x1e` | 동작 |
| **미지의 섬** 입장 · 인원수 · 상대 조회 · 상태 등록 · 방문기록 | `0x121`~`0x127` | 동작 |
| 즐겨찾기 / 친구 | `0x131`~`0x133`, `0x141`~`0x143` | 동작 |
| 랭킹 / 대전 기록 | `0x111`~`0x116` | 동작 |
| 우편함 / 선물 | `0x45`~`0x48` | 동작 |
| 경매장 | `0x101`~`0x105` | 동작 |
| 통신사 결제 | `0x39`, `0x3a` | 항상 거절 |

프로토콜 33개 명령 전부에 핸들러가 있습니다. 다만 페이로드 안쪽 필드 중
아직 의미를 확정하지 못한 것들이 있고(주로 미지의 섬의 `char[8]` /
`char[10]` 덩어리), 그런 값은 **받은 그대로 저장했다가 그대로 돌려주는**
방식이라 의미를 몰라도 플레이어끼리는 정상적으로 보입니다.
확정되지 않은 부분은 `docs/protocol.md` 5절에 정리해 뒀습니다.

실제 단말로 한 번 붙여 보면서 다듬을 때는 서버를 `--record` 로 띄우세요.
오간 패킷이 전부 JSONL 로 남습니다.

```bash
python3 server/main.py --record packets.jsonl
```

## 함께 들어 있는 것: 웹 게임 「미지의 해안」

원작의 **그래픽과 게임 스타일**을 참고해 새로 만든 몬스터 수집 RPG입니다.
`web/index.html` 하나로 끝나고 빌드가 필요 없습니다 — 브라우저로 열면 바로 돌아갑니다.

240×320 화면, 16×16 타일, 2×2 디더링까지 원작에서 확인한 규격을 그대로 따랐고,
색은 원작 에셋에서 뽑은 값을 기준으로 잡았습니다. 다만 **리소스는 한 장도 쓰지 않았습니다** —
타일도 몬스터도 배경도 전부 실행 시점에 코드로 그립니다.

필드 탐험 · 키풀 인카운트 · 턴제 전투(5속성 상성) · 포획 · 진화 · 도감 · 자동 저장이
들어 있습니다. 자세한 내용은 [web/README.md](web/README.md).

## 알아 둘 것

- **식별자가 전화번호입니다.** 에뮬레이터는 전부 `01123456789` 로 고정돼서
  같은 계정이 됩니다. 대응 방법은 `docs/setup.md` 3절.
- **도메인은 못 씁니다.** 클라이언트가 `inet_addr()` 를 쓰기 때문에 IPv4
  주소만 가능합니다. IP 가 바뀌면 APK 를 다시 패치해야 합니다.
- **원본 APK 는 이 저장소에 없습니다.** 도구들은 사용자가 가진 파일을
  입력으로 받습니다.

## 테스트

```bash
python3 -m pytest tests -q
```

분석 도구(`tools/disasm.py`, `tools/extract_protocol.py`)는 `capstone` 이
필요합니다: `pip install capstone`. 서버 자체는 필요 없습니다.
