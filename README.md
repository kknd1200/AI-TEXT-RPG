# AI-TEXT-RPG

## 쿼터뷰 픽셀 액션 RPG

외부 라이브러리 없이 도는 단일 페이지 게임이다. 캐릭터·몬스터·스킬 이펙트는
`assets/` 의 픽셀아트를 쓰고, 바닥 타일과 지형지물은 코드로 그려서 캔버스에 굽는다.

```
npx http-server -p 8080 .      # 아무 정적 서버나 상관없다
```
열어서 `http://localhost:8080` 로 접속한다. 에셋을 `fetch` 로 읽기 때문에
`index.html` 을 파일로 바로 열면(`file://`) 브라우저가 로딩을 막는데,
이 경우 자동으로 도형 스프라이트로 대체되어 게임 자체는 그대로 돌아간다.

### 조작

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 (화면 기준 상하좌우, 쿼터뷰 대각선으로 자동 변환) |
| 마우스 좌클릭 | 기본 공격 (누르고 있으면 연속 공격) |
| 마우스 우클릭 | 우클릭 슬롯에 등록한 스킬 |
| `1` `2` `3` `4` | 각 슬롯에 등록한 스킬 |
| `K` | 스킬 등록 창 (스킬 선택 → 슬롯 클릭) |
| `ESC` | 도움말 / 창 닫기 |
| `P` | 일시정지 |

기본 공격은 무기에 따라 근접 부채꼴 또는 투사체로 나간다.
스킬은 배우는 즉시 빈 슬롯에 자동 등록되며, 스킬 창에서 언제든 바꿀 수 있다.

### 직업

1차 직업 4종, **40레벨에 2차 전직**한다. 전직하면 무기·스탯 성장·스킬이 전부 바뀐다.

| 1차 | 무기 | 2차 전직 |
|---|---|---|
| 기사 | 한손검 | **대검전사**(양손검) / **마검사**(장검) |
| 마법사 | 스태프 | **화염법사** / **냉기법사** / **전격법사** |
| 궁수 | 활 | **신궁**(활) / **베놈**(단검) |
| 사제 | 메이스 | **크루세이더**(메이스) / **클레릭**(스태프) / **수도승**(권법) |

스킬은 1차 5종 + 2차 5종으로 직업당 10종, 전체 70종이다.
시전 방식은 근접 부채꼴 / 투사체 / 자기중심 광역 / 지정 지점 광역 / 돌진·순간이동 /
관통 직선 / 연쇄 / 자기 강화 / 즉시 회복 / 지속 장판 10가지다.

### 진행

몬스터는 때리기 전에 예비동작을 보여준다. 판정은 스윙 중간(8프레임 중 4번째)에
들어가므로, 휘두르는 걸 보고 빠지면 근접 공격은 피할 수 있다.

웨이브 방식이다. 적을 전부 정리하면 다음 웨이브가 시작되고 5웨이브마다 보스가 나온다.
몬스터 강함은 **플레이어 레벨을 주축으로, 웨이브를 추가 압박**으로 계산해서
레벨만 올려 쉬워지거나 웨이브만 밀려 감당 못 하는 상황을 막는다.
진행 상황은 브라우저 `localStorage` 에 자동 저장된다.

### 에셋

`assets/` 의 그림은 전부 `index_story_1.html` 안에 base64 로 박혀 있던 픽셀아트를
꺼내 쓴 것이다. 추출·가공은 `tools/build-assets.js` 가 한다.

```
node tools/build-assets.js <원본 index_story_1.html> [몬스터 공격 GIF 폴더]
```

- 직업 GIF 9종 → 프레임을 뜯어 가로 스프라이트 시트(PNG)로 저장. 대기 동작이 그대로 살아 있다
- 몬스터 8프레임 공격 GIF 32종 → 좌우 반전(원본은 왼쪽을 봄) 후 여백을 잘라
  스프라이트 시트로 저장. 대기 모습도 이 시트의 첫 프레임을 쓴다 —
  원본 HTML 의 정지 몬스터 그림과는 그림체가 달라, 섞으면 공격할 때마다
  다른 몬스터로 바뀌어 보이기 때문이다
- 몬스터 정지 PNG → 공격 시트가 없는 몬스터에만 쓴다
- 스킬 이펙트 WEBP 27종 → 8프레임 시트. 손실 재인코딩으로 용량을 1/4 로 줄였다
- 각 그림의 투명 여백을 뺀 실제 경계(bbox)를 재서 `manifest.json` 에 넣는다.
  렌더러는 이 값으로 발 위치를 맞추고 크기를 통일한다

직업 14종에 그림은 9종뿐이라, 모자라는 5종(마검사·화염법사·전격법사·신궁·클레릭)은
캔버스 `color` 블렌드로 색조만 바꿔 쓴다. 명암이 유지돼서 다른 캐릭터로 보인다.

### 파일 구성

```
index.html      화면 구조 (HUD / 직업 선택 / 전직 / 스킬창)
css/style.css   UI 스타일
assets/         픽셀아트 + manifest.json
tools/          원본 HTML 에서 에셋을 뽑는 빌드 스크립트
js/data.js      직업 · 2차 전직 · 스킬 · 몬스터 · 성장 곡선 (순수 데이터)
js/assets.js    에셋 로더 · 색조 변경
js/sprites.js   타일 · 지형지물 생성기 (에셋 없을 때의 대체 캐릭터 포함)
js/input.js     키보드 / 마우스
js/engine.js    월드 · 전투 · 스킬 해석 · 웨이브
js/render.js    아이소메트릭 렌더러
js/ui.js        HUD 및 모달
js/main.js      루프 · 저장
```

스프라이트는 원본 픽셀 크기 그대로 그린다(확대·축소 없음). 그래서 거리·속도 값은
`data.js` 아래쪽의 `WORLD_SCALE` 에서 한 번에 환산한다 — 위쪽 데이터는 읽기 좋은
기준값으로 두고, 아트 크기가 바뀌면 이 숫자만 고치면 된다.

렌더러의 월드→화면 변환은 `sx = wx - wy`, `sy = (wx + wy) / 2` 이고,
캔버스 `transform(1, .5, -1, .5, ox, oy)` 가 정확히 같은 변환이라
원·부채꼴 이펙트는 월드 좌표 그대로 그리면 알아서 마름모로 눕는다.
