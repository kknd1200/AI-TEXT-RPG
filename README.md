# AI-TEXT-RPG

## 쿼터뷰 픽셀 액션 RPG

`index.html` 을 브라우저로 열면 바로 실행된다. 외부 라이브러리·이미지 파일이 없고
스프라이트는 전부 코드로 그려서 캔버스에 굽는다.

### 조작

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 (화면 기준 상하좌우, 쿼터뷰 대각선으로 자동 변환) |
| 마우스 좌클릭 | 기본 공격 (누르고 있으면 연속 공격) |
| 마우스 우클릭 | 우클릭 슬롯에 등록한 스킬 |
| `1` `2` `3` `4` | 각 슬롯에 등록한 스킬 |
| `K` | 스킬 등록 창 (스킬 선택 → 슬롯 클릭) |
| `ESC` | 도움말 / 창 닫기 |
| `P` | 일시정지 |

기본 공격은 무기에 따라 근접 부채꼴 또는 투사체로 나간다.
스킬은 배우는 즉시 빈 슬롯에 자동 등록되며, 스킬 창에서 언제든 바꿀 수 있다.

### 직업

1차 직업 4종, **40레벨에 2차 전직**한다. 전직하면 무기·스탯 성장·스킬이 전부 바뀐다.

| 1차 | 무기 | 2차 전직 |
|---|---|---|
| 기사 | 한손검 | **대검전사**(양손검) / **마검사**(장검) |
| 마법사 | 스태프 | **화염법사** / **냉기법사** / **전격법사** |
| 궁수 | 활 | **신궁**(활) / **베놈**(단검) |
| 사제 | 메이스 | **크루세이더**(메이스) / **클레릭**(스태프) / **수도승**(권법) |

스킬은 1차 5종 + 2차 5종으로 직업당 10종, 전체 70종이다.
시전 방식은 근접 부채꼴 / 투사체 / 자기중심 광역 / 지정 지점 광역 / 돌진·순간이동 /
관통 직선 / 연쇄 / 자기 강화 / 즉시 회복 / 지속 장판 10가지다.

### 진행

웨이브 방식이다. 적을 전부 정리하면 다음 웨이브가 시작되고 5웨이브마다 보스가 나온다.
몬스터 강함은 **플레이어 레벨을 주축으로, 웨이브를 추가 압박**으로 계산해서
레벨만 올려 쉬워지거나 웨이브만 밀려 감당 못 하는 상황을 막는다.
진행 상황은 브라우저 `localStorage` 에 자동 저장된다.

### 파일 구성

```
index.html      화면 구조 (HUD / 직업 선택 / 전직 / 스킬창)
css/style.css   UI 스타일
js/data.js      직업 · 2차 전직 · 스킬 · 몬스터 · 성장 곡선 (순수 데이터)
js/sprites.js   픽셀 스프라이트 생성기 (캐릭터 · 타일 · 지형지물)
js/input.js     키보드 / 마우스
js/engine.js    월드 · 전투 · 스킬 해석 · 웨이브
js/render.js    아이소메트릭 렌더러
js/ui.js        HUD 및 모달
js/main.js      루프 · 저장
```

렌더러의 월드→화면 변환은 `sx = wx - wy`, `sy = (wx + wy) / 2` 이고,
캔버스 `transform(1, .5, -1, .5, ox, oy)` 가 정확히 같은 변환이라
원·부채꼴 이펙트는 월드 좌표 그대로 그리면 알아서 마름모로 눕는다.
