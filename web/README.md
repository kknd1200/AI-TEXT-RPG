# 미지의 해안 — 웹 게임

배틀몬스터3(`com.ensony.battlemonster3`)의 **실제 몬스터와 타일 그래픽**으로 만든
몬스터 수집 RPG입니다. `index.html` 파일 하나로 끝나고, 빌드도 서버도 필요 없습니다.

```bash
xdg-open web/index.html          # 또는 브라우저에 그냥 끌어다 놓기
```

## 그래픽은 전부 원작에서 뽑아냈습니다

| 항목 | 출처 | 수량 |
|---|---|---|
| 몬스터 스프라이트 | `assets/m_b_XXX_1.fbm` | 131마리 |
| 몬스터 이름 · 고유기술 | `assets/item_mon.dat` | 131쌍 |
| 필드 타일 | `assets/m0_0` ~ `m0_6.fbm` | 9종 × 변주 3 |

몬스터 아틀라스 68KB, 타일 아틀라스 5KB — 둘 다 base64로 `index.html` 안에
들어 있어서 외부 파일이 없습니다. 주인공 스프라이트와 전투 배경·타이틀 밤바다는
원작에 대응하는 리소스가 없어 코드로 그립니다.

다시 뽑으려면:

```bash
unzip -q 배틀몬스터3.apk -d apk
python3 tools/rip_monsters.py apk/assets -o web/    # monsters.png + mondata.js
python3 tools/rip_tiles.py    apk/assets -o web/    # tiles.png + tiledata.js
```

두 스크립트가 만든 `MON_ATLAS_SRC` / `MON` / `TILE_ATLAS_SRC` 를 `index.html`
안의 같은 이름 상수와 바꿔치면 됩니다. 포맷을 어떻게 풀었는지는
[../docs/reversing.md](../docs/reversing.md) 의 "리소스 포맷" 절 참고.

## 조작

| 키 | 동작 |
|---|---|
| `↑` `↓` `←` `→` | 이동 · 메뉴 커서 |
| `Enter` / `Space` | 확인 · 대화 넘기기 |
| `Esc` | 취소 · 필드에서는 메뉴 |

화면 아래 방향키와 소프트키를 눌러도 됩니다. 휴대폰에서도 그대로 동작합니다.

## 게임

- **필드** — 52×52 타일 섬. 해안 · 초원 · 숲그늘 · 깊은 안개 네 구역이 있고,
  구역마다 출현하는 속성과 레벨대가 다릅니다. **키풀**을 밟으면 야생 몬스터가 나옵니다.
- **전투** — 턴제. 속도가 높은 쪽이 먼저 칩니다. 풀·물·불·땅·바람 상성,
  급소(7%), 빗나감이 있습니다. 각 몬스터는 **원작의 고유기술**을 그대로 씁니다
  (예: 터틀의 롤링스톤, MC몬의 멍키트윗).
- **포획** — 상대 체력이 낮을수록 잘 잡힙니다. 도감 최상위 5종은 잘 잡히지 않고
  도망칠 수도 없습니다. 파티는 4마리까지, 넘치면 보관함으로.
- **성장** — 레벨업으로 능력치가 오르고, Lv.9에 속성 강기술을 배웁니다.
- **야영지** — 섬 중앙 치유사에게 `Enter`를 누르면 파티가 전부 회복됩니다.
- **도감** — 131칸. 만난 종은 실루엣으로, 잡은 종은 스프라이트와 능력치·고유기술까지.
- **저장** — `localStorage`에 자동 저장. 메뉴에서 수동 저장도 됩니다.

속성은 원작 데이터에 없어서 **이름 규칙으로 배정**했습니다
(`tools/rip_monsters.py`의 `TYPE_RULES`). 능력치도 원작에 없어 도감 순번과
스프라이트 덩치, 속성 성향으로 계산합니다. 진화는 원작에 계보 데이터가 없어
넣지 않았습니다.

## 코드 구성

한 파일 안에서 위에서부터 순서대로 읽으면 됩니다.

```
CSS + HTML        단말기 셸, LCD, 키패드
mondata.js 블록    몬스터 아틀라스(base64) + 131종 메타데이터
난수 · 색 · 서피스   put/commit/dither/noiseField — 픽셀을 찍는 최소 도구
타일 아틀라스        원작 타일을 잘라 캔버스 27장으로
SPECIES / ART     아틀라스를 종별 캔버스로 슬라이스
makeHero          주인공 4방향 × 4프레임 (코드 생성)
데이터             속성 상성, 기술, 능력치 공식
buildIsland       반경 감쇠 + 값 노이즈로 섬 생성
코루틴 러너         전투 연출을 generator로 순서대로 (yield 프레임수 / "input")
drawField/Battle  캔버스 렌더
drawUI            LCD 위 DOM 레이어 — 한글이 또렷하게 나오도록 텍스트는 DOM
key()             모드별 입력 분기
```

**캔버스와 DOM을 섞은 이유**: 240px 폭에 한글 UI를 캔버스로 그리면 확대할 때
전부 뭉갭니다. 그래서 픽셀 그래픽만 캔버스로 그려 정수 배율로 키우고,
글자와 메뉴는 그 위에 DOM으로 얹었습니다.

## 손대기 좋은 곳

- 출현표는 `ZONES` 배열. 속성과 도감 순번 구간으로 지정합니다.
- 지형은 `buildIsland`의 임계값(`h < 0.02` 등).
- 인카운트 빈도는 `S.nextEnc = 5 + rand(9)`.
