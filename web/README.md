# 미지의 해안 — 웹 게임

배틀몬스터3의 **그래픽과 게임 스타일**을 참고해 새로 만든 몬스터 수집 RPG입니다.
`index.html` 파일 하나로 끝나고, 빌드도 서버도 필요 없습니다. 브라우저로 열면 됩니다.

```bash
xdg-open web/index.html          # 또는 브라우저에 그냥 끌어다 놓기
```

## 원작에서 가져온 것과 새로 만든 것

**가져온 것은 "결"입니다.**

| 항목 | 원작에서 확인한 값 | 이 게임 |
|---|---|---|
| 화면 | 240 × 320 | 동일. 정수 배율로만 확대 |
| 타일 | 16 × 16 (`m0_0.fbm` = 208×48, 13×3칸) | 동일 |
| 색 | 8비트 인덱스 팔레트, 마젠타 투명 | 원작 에셋에서 뽑은 색을 기준값으로 사용 |
| 질감 | 2×2 디더링, 부드러운 램프 셰이딩 | 동일한 기법으로 코드 생성 |
| 몬스터 | 30~45px, 말랑한 덩어리 + 진한 외곽선 | 절차 생성 (56×56) |

**리소스는 한 장도 쓰지 않았습니다.** 타일, 몬스터, 주인공, 배경, 상자까지
전부 실행 시점에 코드로 그립니다 (`makeTile`, `makeMonster`, `makeHero`,
`battleBG`, `titleBG`). 원작 팔레트에서 뽑은 색 상수만 참고했습니다.

색을 어떻게 뽑았는지는 [../docs/reversing.md](../docs/reversing.md) 참고.

## 조작

| 키 | 동작 |
|---|---|
| `↑` `↓` `←` `→` | 이동 · 메뉴 커서 |
| `Enter` / `Space` | 확인 · 대화 넘기기 |
| `Esc` | 취소 · 필드에서는 메뉴 |

화면 아래 방향키와 소프트키를 눌러도 됩니다. 휴대폰에서도 그대로 동작합니다.

## 게임

- **필드** — 52×52 타일 섬. 해안 · 초원 · 숲그늘 · 깊은 안개 네 구역이 있고,
  구역마다 나오는 몬스터와 레벨이 다릅니다. **키풀**을 밟으면 야생 몬스터가 나옵니다.
- **전투** — 턴제. 속도가 높은 쪽이 먼저 칩니다. 풀·물·불·땅·바람 다섯 속성의
  상성이 있고, 급소(7%)와 빗나감이 있습니다.
- **포획** — 상대 체력이 낮을수록 잘 잡힙니다. 파티는 4마리까지, 넘치면 보관함으로.
- **성장** — 레벨업으로 능력치가 오르고, Lv.8에 강한 기술을 배웁니다.
  1단계 몬스터는 Lv.12에 진화합니다.
- **야영지** — 섬 중앙 치유사에게 `Enter`를 누르면 파티가 전부 회복됩니다.
- **상자** — 섬 곳곳에 8개. 골드나 구슬, 회복초가 들어 있습니다.
- **저장** — `localStorage`에 자동 저장. 메뉴에서 수동 저장도 됩니다.

## 코드 구성

한 파일 안에서 위에서부터 순서대로 읽으면 됩니다.

```
CSS + HTML        단말기 셸, LCD, 키패드
난수 · 색 · 서피스   put/commit/dither/noiseField — 픽셀을 찍는 최소 도구
makeTile          타일 9종 × 변주 3
makeMonster       메타볼 대신 타원 합집합 → 실루엣이 살아 있는 몬스터
makeHero          주인공 4방향 × 4프레임
데이터             속성 상성, 기술, 도감 16종, 능력치 공식
buildIsland       반경 감쇠 + 값 노이즈로 섬 생성
코루틴 러너         전투 연출을 generator로 순서대로 (yield 프레임수 / "input")
drawField/Battle  캔버스 렌더
drawUI            LCD 위 DOM 레이어 — 한글이 또렷하게 나오도록 텍스트는 DOM
key()             모드별 입력 분기
```

**캔버스와 DOM을 섞은 이유**: 240px 폭에 한글 UI를 캔버스로 그리면 확대할 때
전부 뭉갭니다. 그래서 픽셀 그래픽만 캔버스로 그려 정수 배율로 키우고,
글자와 메뉴는 그 위에 DOM으로 얹었습니다. 픽셀 그림은 픽셀대로,
글씨는 선명하게 나옵니다.

## 손대기 좋은 곳

- 몬스터를 늘리려면 `SPECIES` 배열에 한 줄 추가하면 됩니다.
  스프라이트는 `seed`에서 자동으로 만들어집니다.
- 지형을 바꾸려면 `buildIsland`의 임계값(`h < 0.02` 등)을 만지면 됩니다.
- 인카운트 빈도는 `S.nextEnc = 5 + rand(9)`.
